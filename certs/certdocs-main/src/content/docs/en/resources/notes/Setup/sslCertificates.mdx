Follow these steps to use Certbot to deploy SSL certificates to your domain.

## Certbot Certonly
Certbot is a tool to obtain SSL certificates from Let's Encrypt. The certonly command is used to obtain or renew a certificate without installing it.

### Example
To obtain a certificate using the standalone mode, you can use the following command:
`sudo certbot certonly --standalone -d your_domain`
This command will prompt you to enter an email address and agree to the terms of service. After successful execution, the certificate files will be stored in `/etc/letsencrypt/live/your_domain`.

### Important Considerations
* Port Availability: Ensure that ports 80 or 443 are not in use by other services as Certbot uses these ports to complete the challenge.

* Automatic Renewal: Certbot sets up a scheduled task to automatically renew the certificate. You can test this with: `sudo certbot renew --dry-run`

* Configuration: After obtaining the certificate, you need to configure your application to use it. The private key (`privkey.pem`) and the full chain (`fullchain.pem`) are typically required
