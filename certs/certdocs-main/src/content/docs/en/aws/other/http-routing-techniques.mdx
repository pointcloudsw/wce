   ## Overview
      Main routing patterns when routing http requests:

      - Host-Based
      - Path-Based
      - Header-Based
      - Address-Based
      - Port-Based


      The combination of these patterns can be used to create complex routing rules that can direct traffic based on multiple criteria.  Morever, when combined with authentication, authorization, and other security measures, these routing patterns can help ensure that requests are handled securely and efficiently.  This amounts to validation that a particular command (e.g., HTTP request) is allowed to be executed by the user or service making the request, much like a command shell command that requires validation before execution.
