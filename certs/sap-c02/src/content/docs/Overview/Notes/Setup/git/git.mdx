### [Source](https://git-scm.com/downloads/linux)

#### Option 1
For the latest stable release on Debian/Ubuntu
```sh
apt-get install git
```

#### Option 2
For the latest stable upstream version
```sh
sudo add-apt-repository ppa:git-core/ppa
apt update; apt install git
sudo apt update
sudo apt install git
sudo apt upgrade
```
